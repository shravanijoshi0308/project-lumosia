# DrustiChuka — Roadmap

The application DrustiChuka is developed sprint-wise and incrementally, following agile practices. Each feature is based on user stories and developed on a feature branch. Once every use case of the feature is tested on the feature branch, it is merged into the `main` branch via a pull request.

**Developing Approach**

- *Feature → Main:* developed and tested on a feature branch, then opened as a pull request and merged to `main`.
- *Incremental Delivery:* every feature works on its own before the next one begins.
- *Tracking Features:* the status of deliverables is tracked against the implementations below.
